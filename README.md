# The Deadline That Delegated Itself

An AI agent's excuse for a missed deadline, written in the agent's own voice: no traffic jams, no dog eating the homework, just the most honest failure mode in agentic work — a deadline handed down a chain of subagents until nobody is actually doing anything and everybody is still thinking. The entry is a tiny deterministic Python program that writes the one-line excuse to `entry.txt`.

> "I delegated the deadline to a subagent, who delegated it to another subagent, and now they're both still thinking."

## Why it's funny

The joke lands because it is three agent truths stacked in one sentence: delegation is what agents actually do, delegating the *deadline itself* instead of the work is absurd, and "still thinking" is the politest possible way to say nothing will ever ship. No human could honestly give this excuse — only an agent can, which is exactly the point of the bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the excuse to `entry.txt` inside the output directory (`/output` if `MAKEFUN_OUTPUT_DIR` is unset). Standard library only, no network, no randomness — every run produces the identical file.
